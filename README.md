# RegionControl (Сарыарқа облысы)

**Единая веб-платформа контроля инфраструктурных объектов и состояния дорог для регионального акимата (Республика Казахстан, программа G-TON).**

Платформа решает две фундаментальные задачи региона:
1. **«Единая карта инфраструктурных объектов»**: автоматический контроль жизненного цикла 127 проектов строительства, ремонта и благоустройства с алгоритмическими флагами отставания от графика.
2. **«Дороги области (приложение инспектора)»**: мобильный контроль 1 588 км областных дорог (~20 трасс), геопривязка дефектов за 3 действия и жесткий SLA передачи подрядчику до 5 минут.

**Ключевая ценность продукта:** объект дорожного ремонта в реестре и дефекты полотна (ямы, трещины) на этом же участке принадлежат одному подрядчику. Система связывает их на уровне данных, выявляет **системную недисциплинированность подрядных организаций** и формирует единую сводку для Акима области за минуты без ручных звонков.

## Архитектура и стек технологий

- **Backend**:
  - Python 3.10+ / 3.11, **FastAPI**, **SQLAlchemy 2.0**, **Alembic**, **Pydantic v2**.
  - База данных: SQLite по умолчанию (zero-setup), переход на PostgreSQL / PostGIS переключением переменной `DATABASE_URL` в `.env`.
  - Генерация отчетов: `pandas`, `openpyxl` (Excel) и `reportlab` (векторный PDF).
- **Frontend**:
  - **React 18**, **TypeScript**, **Vite**, **Tailwind CSS**, **Lucide Icons**.
  - Картография: **Leaflet** + **React-Leaflet** (OpenStreetMap, полилинии трасс, цветные геометки статусов).
  - Графика: **Recharts** (воронка стадий, распределение по районам).
  - PWA-адаптив: оптимизирован для смартфонов дорожных инспекторов (камера, HTML5 Geolocation API, offline manifest).
  - Интернационализация: архитектура `i18n` с мгновенным переключением **Русский / Казахский**.
  - Темизация: Светлая и Тёмная темы.
- **ИИ-слой (LLMProvider)**:
  - Абстрактный интерфейс `BaseLLMProvider`.
  - По умолчанию включен детерминированный `MockLLMProvider` (работает полностью офлайн без API-ключей и интернета).
  - Готов к подключению `OpenAI` / `Gemini` / локального `Ollama` через `.env`.

## Ключевые модули платформы

### 1. Дашборд «Контроль региона» (Экран Акима)
- 4 ключевые KPI-карточки, читаемые за 30 секунд:
  - **Объекты в работе**: 127 (в графике / риск / отставание);
  - **Актуальность статусов**: % (KPI 90% обновлено за последние 14 дней);
  - **Покрытие сети осмотром**: % (цель KPI 100% за месяц);
  - **Устранение дефектов в срок**: % (цель 95%) + скорость передачи подрядчику (1.2 мин при нормативе < 5 мин).
- Интерактивная карта области с фильтрацией слоев.
- Топ-5 проблемных подрядчиков с подсветкой системных сбоев.
- Кнопка **«Сформировать сводку ИИ»** — генерация краткого оперативного брифинга в 1 клик.

### 2. Единая карта инфраструктурных объектов
- Реестр 127 проектов с фильтрами по 5 районам, стадиям и флагам.
- Алгоритмический расчет статусов здоровья:
  - факт отстает от плана более чем на 10 п.п.;
  - просрочена веха графика;
  - статус не обновлялся более 14 дней;
  - превышение сметы.
- Выдвижная карточка объекта: лента вех, финансы, смета и **связанные дефекты дороги**.
- Выгрузка реестра в **Excel** и официальный **PDF**.
- Модальное окно быстрого обновления статуса и массовый импорт из CSV.
- Настройка пороговых значений отставания прямо в интерфейсе.

### 3. Дороги области и PWA-экран инспектора
- 20 областных дорог общей длиной **ровно 1 588.0 км**, разбитых на 60 участков.
- Мобильный экран инспектора: фиксация дефекта в **3 действия** (фото с камеры, тип дефекта, GPS).
- Автоматическая геопривязка дефекта к ближайшему участку и назначение закрепленного подрядчика.
- Соблюдение целевого SLA передачи подрядчику до 5 минут.
- Контроль устранения: загрузка фото «после», приёмка или возврат на доработку.
- При приближении или срыве срока — автоэскалация директору подрядчика и в Управление дорог.

### 4. Сквозная связка и рейтинг системной дисциплины
- **Главное отличие продукта**: на карточке ремонта трассы видны активные ямы на участке, а дефект знает, в рамках какого строительного проекта ведутся работы.
- Подрядчики со срывами и по стройкам, и по дорожным дефектам помечаются красным бейджем **«🚨 СИСТЕМНЫЙ СБОЙ»**.
- Просроченный дефект на участке проблемного подрядчика получает повышенный приоритет и экстренно эскалируется в Управление дорог / Акимат.

## Тестирование

Запуск набора автоматических тестов бизнес-правил и API:
```bash
python -m pytest -c backend/pytest.ini backend/tests
```
Проверяются:
- Расчет флагов отставания и актуальности (`test_flag_engine.py`);
- Геопривязка дефекта к участку дороги (`test_road_matcher.py`);
- SLA передачи (<5 мин) и правила эскалации (`test_escalation.py`);
- Матрица системной дисциплины подрядчиков (`test_systemic_rating.py`);
- Интеграционные тесты REST API (`test_api_endpoints.py`).

## Безопасность и приватность

- **Ролевая модель (RBAC)**: Аким, Руководитель управления, Куратор объекта, Дорожный инспектор, Подрядчик (видит только свои заявки).
- **Геолокация инспектора**: фиксируется исключительно в момент подтверждения отправки дефекта, в рабочее время и с явным согласием в интерфейсе. Никакого фонового трекинга.
- **Аудит**: критические действия фиксируются в таблице `audit_logs`.
- **Файловая безопасность**: валидация типов файлов и строгие ограничения размера.
